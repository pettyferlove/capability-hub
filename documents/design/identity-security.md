# 身份与安全设计

## 账号与身份

密码使用随机盐 scrypt；验证不信任损坏的哈希格式。初始化、账号管理和授权变更通过应用层事务执行；最后一个有效平台管理员不能被停用或移除必要授权。

每次解析身份在同一存储事务中读取当前账号、成员关系、角色和绑定，构造 Principal。慢操作完成后，在写事务中复核身份及修订，避免撤权后提交。成员关系本身不直接赋予维护或审核权限；团队绑定角色后，其有效成员继承相应范围的角色授权。

## HTTP 会话和令牌

浏览器使用 HttpOnly 会话 Cookie；生产 Cookie 使用 Secure。修改请求校验 Origin 和 CSRF。请求先检查 Host/Origin，再进行有大小限制的 JSON 解析。不存在的 API 和静态资源不返回 SPA 页面。

消费令牌区分 hub:read 与 hub:contribute，仍受当前用户 RBAC 和内容受众约束。读取令牌不能写入，contribute 只增加明确工具能力；不能据此访问个人会话、凭据和管理 API。无效的显式 Bearer 不降级成匿名；过期 Cookie 在公开读取中按匿名处理。

停用账号会在同一事务中撤销全部网页会话、客户端授权和个人令牌；重新启用账号不会恢复已撤销凭据。密码变更只撤销网页会话，个人令牌和客户端授权仍按独立生命周期管理。

CLI 登录为 challenge/verifier、设备码和一次性浏览器批准。终端显示同实例的批准 URL 和授权码，由用户在浏览器确认；批准、消费和签发共享事务边界，一次批准只签发一个令牌。

个人令牌只在创建时返回原文。账号安全页通过原位侧栏完成命名、权限选择、创建与复制，创建后刷新令牌列表，无需跳转接入页；安装与接入页复用同一创建表单。令牌原文仅保留在当前表单内存中，隐藏或关闭后不可再次查看。CLI 环境令牌必须同时明确 --url；本地凭据绑定原实例，不能通过另一个 URL 覆盖。凭据原子写入私有文件，读取拒绝链接、公开权限和超大文件。

## Git 安全

仓库限定 HTTPS/SSH 和允许域名；URL 不含嵌入凭据、查询或任意协议。全部 DNS 结果都要通过网络策略；私有地址只有同时进入允许列表和显式私网列表才接受。网络层仍需部署方的出站策略，域名检查不替代网络隔离。

凭据只供所属账号选择，可保留来源原绑定；域名和认证类型必须精确匹配，IPv6 主机采用包含方括号的规范形式。AES-GCM 密文绑定凭据 ID、账号、域名和类型。到期、撤销或所属账号停用后不再可用；同步期间轮换修订也会终止旧读取。SSH 必须提供经独立渠道核对的主机公钥，不接受首次连接自动信任。

## 内容与审计

内容不作为可信指令执行。扫描子进程使用独立临时目录、内存限制、超时和受限环境；这不替代容器或主机隔离。预览只渲染受控 Markdown；下载保持字节并提供摘要。

数据库约束保护冻结申请策略、已完成的审核决定、发布、扫描及审计证据；扫描和申请记录不可删除。事件保存当时可用的主体与对象展示快照，缺少关联对象时保留原始 ID。日志对秘密字段及嵌入 URL 脱敏，异常只保留类型、代码和调用位置，不记录任意异常正文。

浏览器诊断使用固定事件/页面集合、请求 ID、批次与字节上限；服务端独立校验来源并限流。采集失败丢弃当前批次，不递归重试。

## Agent OAuth 连接

Hub 同时承载授权服务与 MCP 资源服务。公开元数据提供 DCR、授权码 + S256 PKCE、刷新和撤销端点；只接收公开客户端 `token_endpoint_auth_method=none`，不支持 implicit、密码模式或客户端凭据模式。不抓取客户端远程元数据，因此不声明 CIMD 支持。

注册回调只允许 HTTPS 或 loopback HTTP，禁止凭据、片段和预置的 code/error/state/iss 参数；授权时精确匹配原始 URI 字符串，IP loopback 仅放宽端口。客户端名称是请求方提供的展示信息，不是可信身份。授权页展示账号、目标资源、客户端名称和回调来源；批准/拒绝必须经过网页登录、同源与 CSRF 校验。拒绝后返回标准 access_denied；过期请求需重新开始。

授权码有效期 60 秒，绑定客户端、完整回调、资源及 PKCE，事务内一次消费。响应包含 iss 和原始 state；助手验证二者。访问凭据有效期一小时，刷新凭据有效期 30 天且每次使用轮换；重放已消费凭据会永久撤销该连接。凭据只存摘要，刷新不能扩大授权范围。默认只授予读取；贡献权限即使由客户端请求，也必须由用户在授权页主动选择。

OAuth 凭据仅用于 `/mcp`，不能调用目录 HTTP、个人或管理 API；个人手动令牌继续遵循原有消费边界。每次 MCP 请求检查有效账号、当前 RBAC、连接撤销及凭据有效期；刷新后也不能恢复已撤销连接。密码变更只撤销网页会话；停用账号在同一事务中撤销全部连接，并作废已批准但尚未兑换的 OAuth 和 CLI 登录，重新启用不会恢复。

公开协议端点提供无凭据 CORS；授权确认和账号接口仍受同源与 CSRF 约束。匿名 OAuth 端点有有界的单进程请求速率限制，注册与刷新使用独立额度；客户端注册没有隐含的闲置过期，维护任务不会删除仍可用于重新授权的注册。生产多实例应由入口代理补充整体限流。授权码、令牌和 PKCE verifier 不进入应用日志。身份相关表包含在各后端唯一的 Drizzle 初始迁移中，后续结构变更随迁移历史执行；未纳入当前迁移体系的旧数据库不提供转换或兼容路径。

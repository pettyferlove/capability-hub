# 使用 Capability Hub

先确认用户指定的 Hub 实例。任务需要 MCP 且尚未连接时，从实例地址读取公开的 `/INSTALL.md`，完成验证后继续原任务。调用时使用该连接实际发现的工具及其参数，客户端可能为工具名加上服务前缀。只读检索成功但结果为空，表示当前账号在该查询下没有可见匹配项。

## 查找并使用团队能力

- **当次使用规范或经验**。用任务关键词调用 `search_skills`，按描述、适用条件和可见版本选择结果。取 `current_release.version_id` 调用 `load_skill`，需要附属资料时按返回清单用 `read_skill_file` 读取同一版本。按需翻页，然后继续用户的任务。这条路径无需写入本地目录。
- **安装到客户端**。用户要求持久安装时，向 `install_skill` 提供选定的版本和客户端标识。按 `next_offset` 取完同一版本的分块，逐块解码并按偏移拼接，核对归档摘要及清单中的文件路径、大小、摘要。确认目标目录、文件和已有同名内容的处理方式后写入完整目录。报告实际保存位置。需要执行脚本时另行取得授权。
- **使用目录里的 MCP 服务**。用 `search_mcp` 选择固定版本和受支持的安装项。只需配置时调用 `get_mcp_config`，准备接入时直接调用 `activate_mcp`。使用结果中的客户端配置、变量说明和注意事项。含共享密钥的配置只交付到客户端私有位置，对话中隐藏密钥。用户确认后合并配置、重载并发现目标服务的工具，再报告实际连接结果。

## 分享、推荐和反馈

- **邀请同事使用这个 Hub**。读取该实例的公开接口 `/api/hub-share`，将返回的 `prompt` 原样交给用户。
- **将本地 Skill 提交给团队**。确认文件清单、维护团队或已有资产，以及版本。只提交用户选定的 Skill 文件，包括根目录的 `SKILL.md`，排除凭据和私人记录。新建时使用已确认的 `owner_group_id`，更新时使用 `asset_id`。无法确定维护团队时引导用户在 Hub 发布页选择。用 `share_skill` 提交，同一次提交重试复用 `idempotency_key`。返回 `submitted_for_scanning` 时报告“已提交扫描”，给出返回的发布页，由用户选择共享受众并提交独立审核。
- **推荐或反馈某个版本**。用户要求推荐或取消推荐时，对该版本调用 `rate_asset`。反馈缺陷、能力缺口或建议时，先确认本次或已有的上报授权，再对固定版本调用 `report_asset_feedback` 并声明 `consent: true`。仅提交脱敏的最小复现场景，分开记录观察和推断，同一次上报重试复用幂等键。

只读连接看不到贡献工具。有贡献任务时，引导用户到该实例的 `/connect?permission=contribute` 重新授权，刷新后核对所需工具。工具出现后仍须满足账号的资产权限。工具返回错误时按实际结果报告，保留当前版本与任务上下文。
